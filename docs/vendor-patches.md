# Vendor patches

Vendored downstream fixes are exceptional. Each entry records why the change
cannot yet be represented by a module version and how to remove it safely.

`go-cli-server` and `vt10x` are our own modules
(`github.com/standardbeagle/...`). A fix to either lands upstream as a tagged
release and agnt bumps to it; `vendor/` is regenerated by `go mod vendor` and
must match the pinned versions byte for byte.

There are currently no vendor patches. The go-cli-server v0.5.4 Windows
`hasReleasedResources` shim that used to be listed here shipped upstream and is
part of the pinned v0.5.8.
